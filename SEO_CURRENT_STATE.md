## 3. Найдено и исправлено в этом заходе

Всё ниже — **FACT**, изменения в коде, задеплоены.

1. **`/course.html`** был закрыт `noindex`, но лежал в sitemap.xml. Противоречивый сигнал для краулера. → генератор sitemap теперь сам читает `<meta name="robots">` и выкидывает `noindex`-страницы. Проверять руками больше не нужно.
2. **`/newdesign.html`** — полная копия главной, открытая для индексации. Классический дубль. → закрыт `noindex,nofollow`.
3. **`twitter:card` отсутствовал на всём сайте** (0 страниц из 20). → добавлен `summary_large_image` на 20 файлов.
4. **`<img>` в `<noscript>` Meta Pixel без `alt`** на 18 страницах — замечание доступности, которое видят и аудиторы Bing. → добавлен пустой `alt=""`.
5. **`/musiclab/alterigor/blizhe/`** существовала, но отсутствовала в sitemap (сирота). → подхватывается генератором автоматически.
6. **Sitemap собирался руками** и отставал от репозитория. → `scripts/generate-sitemap.js`: обход файлов, `lastmod` из `git log`, проверка self-canonical, правила приоритетов.

## 4. Осталось незакрытым (честный список)

**FACT — проблемы, которые я не закрыл:**

- **Длина `<title>`**: 8 страниц длиннее 62 символов из-за префикса «Prodigy LAB · ». Bing и Google обрежут хвост. Требуется ручная переформулировка на каждом языке — автозамена испортит смысл.
- **Длина `<meta description>`**: часть описаний длиннее 165 символов, тоже обрежется.
- **Нет JSON-LD** на `/prodigybot/`, `/privacy/`, `/content-standard/` и их зеркалах. На 11 новых посадочных разметка есть.
- **`www`** не работает (см. выше).
- **Нет Google-тега.**
- **Нет реальных скриншотов и цифр кейсов** на `/prodigybot/` — блок доказательств пустует.

**RECOMMENDATION:** первыми закрывать `www` и title/description — это влияет на CTR из выдачи, а не только на техническую чистоту.

## 7. Требует ручных действий владельца

Я это сделать не могу — нужен доступ в кабинеты.

1. **Vercel → Project → Settings → Domains → Add `www.prodigylab.studio`.** DNS уже настроен правильно, Vercel сам выпустит сертификат за пару минут. Без этого `www` отдаёт TLS-ошибку.
2. **Bing Webmaster Tools** — верификация и загрузка sitemap. Пошагово: `BING_SETUP_MANUAL.md`.
3. **Bing Places** — решение по формату (сервисная зона без адреса). Пошагово: `BING_PLACES_SETUP.md`.
4. **Google-тег** — прислать ID (`G-…` или `GTM-…`), поставлю на все страницы за один заход.
5. **Кейсы** — скриншоты и цифры для блока доказательств на `/prodigybot/`.

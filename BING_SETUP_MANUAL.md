# Bing Webmaster Tools — подключение prodigylab.studio

Пошагово. Всё в этом файле требует **твоего логина** — я это сделать не могу.
Время: 15–20 минут. Дальше данные копятся сами.

---

## Зачем

Пока Bing Webmaster Tools не подключён, **у нас нет ни одной цифры** по органике из Bing: ни показов, ни кликов, ни позиций, ни списка проиндексированных страниц. Всё, что можно сказать без него, — это состояние кода, а не результат. Поэтому это первый шаг, а не последний.

Отдельно: Bing — это ещё и поиск внутри Windows, Edge, Yahoo, DuckDuckGo (частично) и **источник для ChatGPT Search**. Для B2B-аудитории в США это не «остатки после Google».

---

## Шаг 1. Аккаунт

1. Открыть <https://www.bing.com/webmasters>
2. Войти. Использовать **рабочий** Microsoft-аккаунт, не личный — чтобы доступ не потерялся.
3. Если аккаунта Microsoft нет — завести на рабочую почту.

---

## Шаг 2. Добавить сайт

На выбор два пути.

### Путь А — импорт из Google Search Console (быстрее)
Кнопка «Import from Google Search Console». Bing подтянет и верификацию, и сайты.
**Ограничение:** у нас GSC тоже не подключён. Так что этот путь пока закрыт — оставляю на будущее.

### Путь Б — добавить вручную (наш случай)

1. В поле «Add site manually» ввести: `https://prodigylab.studio`
2. Bing предложит три способа верификации. **Выбирай XML-файл** — он самый надёжный на статике.

---

## Шаг 3. Верификация — СДЕЛАНО 04.09.2026

**Статус: тег установлен и раскатан.** В `<head>` главной, сразу после `viewport`:

```html
<meta name="msvalidate.01" content="F49FB5139071EDA53E1B8CC76652A8D8" />
```

Проверено на живом сайте, в том числе с user-agent `bingbot` — тег отдаётся. Осталось нажать **Verify** в кабинете.

Тег стоит только на главной (`https://prodigylab.studio/`) — именно этот URL добавлен в кабинет, для проверки владения домена этого достаточно.

<details>
<summary>Старая инструкция (на случай, если тег придётся менять)</summary>

### Верификация через XML-файл

1. Bing даст скачать файл `BingSiteAuth.xml` с уникальным токеном внутри.
2. Пришли мне этот файл или просто содержимое — я положу его в корень репозитория и задеплою.
   Он должен открываться по адресу `https://prodigylab.studio/BingSiteAuth.xml`
3. После деплоя (~40 секунд) нажать в Bing «Verify».

**Альтернатива, если хочешь без меня:** способ через meta-тег. Bing даст строку вида
`<meta name="msvalidate.01" content="XXXXXXXX" />` — пришли её, я вставлю в `<head>` главной. Работает так же.

**Третий способ — CNAME-запись в DNS** — не советую: сайт на Cloudflare, лишний риск задеть боевые записи ради того, что решается тегом.

</details>

## Шаг 4. Загрузить sitemap

После верификации:

1. Раздел **Sitemaps** → «Submit sitemap»
2. Вставить: `https://prodigylab.studio/sitemap.xml`
3. Отправить.

На момент написания в sitemap **40 URL**, все — с self-canonical, без `noindex`. Файл генерируется скриптом (`npm run sitemap`), руками его править не надо.

---

## Шаг 5. Привязать ключ IndexNow

IndexNow уже работает и **не требует** Bing Webmaster Tools — первая отправка 32 URL прошла с кодом 202 ещё до подключения кабинета. Но в кабинете появится раздел статистики по заявкам.

1. Раздел **IndexNow**
2. Bing сам увидит ключ `36a8f3d2d56a946777c590357b4fbf40` по файлу в корне.
3. Если попросит подтвердить — ключ и адрес файла лежат в `INDEXNOW.md`.

---

## Шаг 6. Что включить сразу после верификации

| Раздел | Действие |
|---|---|
| **Site Scan** | запустить первый скан — Bing сам найдёт технические ошибки |
| **URL Inspection** | проверить `/`, `/en/`, `/website-audit/`, `/prodigybot/` — видит ли Bing их так же, как браузер |
| **Robots.txt Tester** | убедиться, что ничего лишнего не закрыто |
| **Crawl Control** | оставить по умолчанию; сайт статический, нагрузка не проблема |
| **Email notifications** | включить — иначе об ошибках узнаем через месяц |

## Шаг 7. Через 7 дней

Вернуться в **Search Performance** и снять первые цифры: показы, клики, средняя позиция, по каким запросам. **Раньше семи дней данных не будет** — Bing копит их с задержкой, и любые выводы на третий день будут выдумкой.

Эти цифры идут в первый недельный отчёт `reports/bing-seo/`.

## Чего делать не надо

- **Не покупать** «ускоренную индексацию» и «продвижение в Bing» — таких услуг у Microsoft нет, всё это мошенники.
- **Не отправлять** один и тот же URL в IndexNow каждый день. Скрипт специально считает хэши и шлёт только изменившееся.
- **Не добавлять** отдельно `www.prodigylab.studio` как второй сайт. Домен уже работает и отдаёт 308 на основной — это правильное поведение, и заводить под него отдельную карточку в кабинете не нужно.

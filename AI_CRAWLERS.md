## Поддомен сканера — scan.prodigylab.studio

Отдельный хост, обслуживается Cloudflare, robots.txt формируется Cloudflare, а не нашим репозиторием.

| Провайдер | Краулер | robots.txt | HTTP | Комментарий |
|---|---|---|---|---|
| OpenAI | `OAI-SearchBot` | Allow | 200 | Не в списке блокировки — доступ есть |
| OpenAI | `GPTBot` | **Disallow** | 200 | Заблокирован Cloudflare Managed robots |
| Anthropic | `ClaudeBot` | **Disallow** | 200 | Заблокирован Cloudflare Managed robots |
| Perplexity | `PerplexityBot` | Allow | 200 | Не в списке блокировки — доступ есть |
| Microsoft | `bingbot` | Allow | 200 | Доступ есть |
| Google | `Google-Extended` | **Disallow** | 200 | Заблокирован |
| Apple | `Applebot-Extended` | **Disallow** | 200 | Заблокирован |
| Meta | `meta-externalagent` | **Disallow** | 200 | Заблокирован |
| Common Crawl | `CCBot` | **Disallow** | 200 | Заблокирован |
| Amazon | `Amazonbot` | **Disallow** | 200 | Заблокирован |
| ByteDance | `Bytespider` | **Disallow** | 200 | Заблокирован |

Плюс на всех действует `Content-Signal: search=yes, ai-train=no, use=reference` — разрешён поиск и цитирование со ссылкой, запрещено обучение.

**HTTP везде 200:** robots.txt — это договорённость, а не блокировка. Добросовестные краулеры её соблюдают, недобросовестные игнорируют. Ориентироваться надо на колонку robots.txt, а не на код ответа.

**Обход:** страница [`/scan/`](https://prodigylab.studio/scan/) на основном домене описывает бесплатную проверку статическим HTML и открыта всем. Поддомен для понимания сервиса AI-системам больше не нужен.

**Как снять блокировку, если решите:** Cloudflare → домен → AI Crawl Control → отключить блокировку AI-краулеров или отредактировать managed robots.txt. Это делается только в дашборде, из репозитория недоступно.

## Про GPTBot: почему он оставлен разрешённым

Это единственное место, где политика могла бы поменяться, поэтому объясняю отдельно.

`GPTBot` и `OAI-SearchBot` — **разные агенты с разным назначением**. `OAI-SearchBot` индексирует сайт для ChatGPT Search: он отвечает за то, попадёт ли Prodigy LAB в ответ со ссылкой. `GPTBot` собирает данные, которые могут использоваться при обучении моделей. **Закрытие GPTBot не мешает цитированию в ChatGPT Search** — эти два вопроса не связаны.

До правки `GPTBot` был разрешён — по общему правилу `User-agent: * Allow: /`. Я оставил его разрешённым и записал это явно. Политику не менял: закрывать ли свой контент от обучения моделей — решение владельца бизнеса, а не техническое.

**Если решите закрыть**, в `robots.txt` меняется ровно одна строка:

```
User-agent: GPTBot
Disallow: /
```

Ровно то же соображение применимо к `Google-Extended`, `Applebot-Extended` и `meta-externalagent`.

## Чего в этой таблице нет

- **Никаких «секретных AI-тегов».** Их не существует. Всё, что здесь используется, — robots.txt, sitemap, JSON-LD, семантический HTML: обычные веб-стандарты.
- **Никаких гарантий попадания в ответы.** AI-системы сами решают, что цитировать. Технический доступ — необходимое условие, но не достаточное.
- **Никаких выдуманных user-agent.** Если агента нет в публичной документации оператора, его нет и в этой таблице.

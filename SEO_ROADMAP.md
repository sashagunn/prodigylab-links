## Как поймём, что это сработало

Метрика успеха — **не позиции**. Позиции легко растут по запросам, которые никто не ищет.

Смотрим по порядку значимости:

1. Обращения из органики (Free Scan, форма, директ) — единственная метрика, которая платит
2. Клики из Bing на страницы услуг
3. Показы и охват запросов
4. Число страниц в индексе

Первые осмысленные данные — не раньше конца недели 2, и только если Bing Webmaster Tools подключён. До этого любой отчёт о «росте» будет выдумкой.

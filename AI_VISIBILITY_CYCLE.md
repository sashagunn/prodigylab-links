## Чек-лист

| # | Шаг | Как |
|---|---|---|
| 1 | Доступность краулеров | `npm run check:ai` — прогоняет 15 агентов по живому сайту и печатает коды |
| 2 | Изменился ли robots.txt | `curl -s https://prodigylab.studio/robots.txt \| diff - robots.txt` |
| 3 | robots на поддомене сканера | `curl -s https://scan.prodigylab.studio/robots.txt \| grep -A1 'ClaudeBot\|GPTBot'` — Cloudflare может поменять managed-блок без предупреждения |
| 4 | Ошибки 403 / 429 | видно в выводе шага 1; отдельно — логи Vercel |
| 5 | sitemap | `npm run sitemap`, сверить число URL с прошлой неделей |
| 6 | Переходы из AI | Meta Events Manager → событие `AIReferral`, разбивка по `ai_source` |
| 7 | Какие страницы приводят AI-трафик | там же, параметр `landing_page` |
| 8 | Новые вопросы от клиентов | из переписок Chatwoot и директа за неделю |
| 9 | Обновить 1–2 страницы | добавить ответ на реально заданный вопрос в блок Q&A |
| 10 | Один новый Q&A-блок | по теме из роадмапа ниже |
| 11 | Сверить факты и цены | `BUSINESS_FACTS.json` против `/en/pricing/`; при расхождении правится JSON, потом `npm run facts` |
| 12 | Внутренние ссылки | `npm run check:links` — битых быть не должно |

После правок:

```bash
npm run all && git add -A && git commit -m "..." && git push origin main
```

Подождать раскатку, затем `npm run indexnow`. Отчёт — в `reports/ai-visibility/YYYY-MM-DD.md` из шаблона.

## Правило, которое важнее чек-листа

Ни один пункт выше не даёт попадания в AI-ответы сам по себе. Доступность краулеров — это условие, чтобы нас **могли** процитировать. Цитируют за то, чего нет у других: конкретные цифры, реальная методика, честно названные ограничения.

Поэтому если на неделе выбирать между «прогнать чек-лист» и «написать один настоящий ответ на вопрос, который вчера задал клиент» — писать ответ.

## Роадмап контента под реальные вопросы

Темы взяты из вопросов, которые люди задают AI-системам и задают нам на созвонах. Каждый материал должен вести на конкретную ступень воронки — иначе он не пишется.

Формат один и тот же: **вопрос заголовком → прямой ответ первым абзацем → детали → что делать дальше.** Не «10 советов», не 400 слов вступления перед ответом.

### Shopify

| Вопрос | Куда ведёт | Что уникального можем сказать |
|---|---|---|
| Почему на сайт идёт трафик, а продаж нет | `/website-audit/` | Порядок проверки: сначала релевантность трафика, потом страница, потом оффер. Большинство переставляет местами |
| Редизайн магазина или смена рекламы — что первым | `/shopify-audit/` | Признаки, по которым видно, что проблема в трафике, а не в сайте |
| Сколько на самом деле стоит редизайн Shopify | `/shopify-redesign/` | Наши реальные вилки: $2,900 / $5,900 / от $9,900 и что попадает в каждую |
| Как понять, что магазин плохо конвертит | `/conversion-rate-optimization/` | Что видно снаружи без доступов, а что — только по аналитике |

### Реклама

| Вопрос | Куда ведёт | Что уникального можем сказать |
|---|---|---|
| Клики есть, продаж нет — что не так с Meta Ads | `/meta-ads-management/` | Четыре причины по порядку частоты, из практики ведения кабинетов |
| Чинить сайт до увеличения бюджета или после | `/website-audit/` | Простой расчёт, при какой конверсии рост бюджета усиливает убыток |
| Как понять, реклама виновата или посадочная | `/meta-ads-management/` | Разделение по данным, а не по ощущению |
| Google или Meta первым | `/google-ads-management/` | Есть ли существующий спрос — единственный вопрос, который решает |

### Сайт

| Вопрос | Куда ведёт | Что уникального можем сказать |
|---|---|---|
| Как понять, что сайт теряет клиентов | `/scan/` → `/website-audit/` | Что показывает бесплатная проверка и чего она принципиально не видит |
| Что чинить на сайте первым | `/website-audit/` | Порядок: скорость ответа на заявку → соответствие страницы запросу → всё остальное |
| Когда сайт пора переделывать, а когда нет | `/website-redesign/` | Когда редизайн — это дорогой способ не решить проблему |

## Чего в этом цикле нет намеренно

- **Метрик вида «AI Rank 87» и «ChatGPT Authority 92».** Таких метрик не существует. Их продают те, кто их же и придумал.
- **Обещания попасть в ответы ChatGPT.** Решает система, не мы.
- **Ежедневной проверки краулеров.** Раз в неделю достаточно; чаще — это имитация работы.

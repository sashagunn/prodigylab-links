## IndexNow — перепроверено по существу, не только по значению `fetch-depth`

Старая причина (push из нескольких коммитов 05.10, `fetch-depth: 2`) воспроизведена локально на реальных SHA этого репозитория и подтверждена: `fatal: bad object 2525642e...`, точь-в-точь как в логе CI.

Новая логика проверена на трёх сценариях (не только «стало 0 → значит починили»):

| Сценарий | Результат |
|---|---|
| Обычный diff с реальными изменениями (05.10, воссоздан на настоящих SHA) | 5 URL, корректно |
| Действительно пустой diff (коммит сам с собой) | 0 URL, **без ошибки** — легитимный ноль |
| `before` = нулевой SHA (новая/пересозданная ветка) | явная `::error::`, шаг падает — **больше не маскируется как 0** |
| `before` — недоступный коммит (force-push) | явная `::error::`, шаг падает — то же самое |

Раньше ошибка `git diff` пряталась не из-за `|| true` (это было излишней подстраховкой) — пустой stdout от упавшего `git diff` просто тёк дальше по пайпу и давал пустой `changed.txt`, и ничего ниже не проверяло код возврата самого `git diff`. Сейчас код возврата `git diff` проверяется явно, до любой текстовой обработки.

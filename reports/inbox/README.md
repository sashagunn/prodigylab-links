# reports/inbox — выгрузки для недельного цикла

Сюда кладутся данные, до которых облачный агент сам не дотягивается. Он читает эту папку
каждый понедельник и, если файлы есть, строит отчёт на реальных числах вместо пометки
«данных нет».

## Что класть

| Файл | Откуда | Как часто |
|---|---|---|
| `bing-YYYY-MM-DD.csv` | Bing Webmaster Tools → Search Performance → Export | раз в неделю |
| `gsc-YYYY-MM-DD.csv` | Google Search Console → Performance → Export | когда подключим |
| `meta-ai-referrals-YYYY-MM-DD.csv` | Meta Events Manager → событие `AIReferral`, разбивка по `ai_source` | раз в неделю |
| `leads-questions-YYYY-MM-DD.md` | реальные вопросы из Chatwoot и директа, просто списком | раз в неделю |

Даты в именах — понедельник той недели, к которой относятся данные.

## Правила

- **Ничего не переименовывать и не редактировать вручную.** Выгрузка как есть — это её ценность.
- Персональные данные из переписок сюда не класть: агенту нужен вопрос, а не имя, телефон и почта клиента. Вопросы обезличивать.
- Если файла за неделю нет — ничего страшного. Агент честно напишет «данных нет» и сделает всё остальное.

## Почему это нужно

У облачного агента нет доступа в Bing Webmaster Tools и Chatwoot: он работает в изолированном
окружении с чекаутом репозитория. Всё, что можно измерить с сайта снаружи, он измеряет сам
(доступность краулеров, битые ссылки, sitemap, логи IndexNow). Всё, что живёт за логином,
попадает к нему только через эту папку.
